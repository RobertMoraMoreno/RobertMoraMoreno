## 📧 Proyecto Destacado: Plantillas de Correo Electrónico para Feria Valencia

📂 Repositorio: [github.com/RobertMoraMoreno/Feria](https://github.com/RobertMoraMoreno/Feria)

Creación de cuatro plantillas innovadoras diseñadas para resaltar los eventos y actividades de la feria, con el objetivo de captar la atención de los usuarios y proporcionar una experiencia visual atractiva y funcional.

**Características destacadas:**
- 📱 Diseño responsive adaptado a diferentes dispositivos
- ⚙️ Uso de MJML y XML para codificación eficiente y compatible con diversos clientes de correo electrónico
- ♿ Enfoque en la usabilidad y accesibilidad del usuario final
